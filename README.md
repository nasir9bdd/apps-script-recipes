Each recipe has a step-by-step video on YouTube: [Apps Script Recipes playlist](https://www.youtube.com/playlist?list=PLGHFsC1aF4YM). Start with recipe #1 if you have never authorized a script before.

## How to use any recipe

1. Open the recipe folder and copy everything in `Code.gs`.
2. In your Google Sheet: **Extensions → Apps Script**, paste it, edit the **SETTINGS** block, and click **Save**.
3. Reload the sheet and use the **⚡ Automations** menu.

Videos go live one per day, so some links open once their video is published.
